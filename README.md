# Sistema de Gestão de Suporte (ACIB / GIAV)

Repositório oficial do MVP desenvolvido para a gestão integrada e suporte operacional, estruturado com arquitetura robusta em backend e foco em acessibilidade digital e ODS 10.

---

##  Sobre o Projeto
O sistema foi concebido para otimizar os fluxos operacionais e o cadastro unificado, eliminando processos manuais e garantindo maior transparência, agilidade e inclusão digital.

## 🛠️ Tecnologias Utilizadas
* **Backend:** Java, Spring Boot
* **Banco de Dados:** MySQL / PostgreSQL
* **Controle de Versão:** Git e GitHub
* **Hospedagem / Deploy:** Render (Nuvem)

##  Funcionalidades Principais
* Cadastro unificado e gestão de registros.
* Interface responsiva com recursos de acessibilidade (alto contraste).
* Endpoints RESTful integrados ao banco de dados.
